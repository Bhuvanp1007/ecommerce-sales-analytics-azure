# Power BI Dashboard

This folder contains the Power BI dashboard developed for the
E-Commerce Sales Analytics project.

## Dashboard Overview

The dashboard provides an interactive view of e-commerce sales
performance using the processed sales data.

## Key KPIs

- Total Revenue
- Total Orders
- Total Units Sold
- Average Order Value

## Visualizations

- Total Revenue by Month
- Total Revenue by Category
- Total Revenue by City
- Total Revenue by Product
- Revenue by Payment Method
- Revenue vs Units Sold

## Filters

- Category
- City
- Order Date

## Technology

- Microsoft Power BI
- Power Query
- DAX
- Azure SQL Database
